# medtriage-app
# MedTriage – Inteligentny system wsparcia wywiadu i organizacji rejestracji dla placówek medycznych

## Główne funkcjonalności:

#### Analiza objawów z wykorzystaniem Google Gemini AI.
#### Zabezpieczenia typu Guardrails (automatyczne wykrywanie stanów zagrożenia życia i przekierowanie na numer 112).
#### Panel Administratora z uwierzytelnianiem dwuetapowym (MFA TOTP) i kolejką pacjentów w czasie rzeczywistym (Supabase Realtime).
#### Bezpieczne zarządzanie danymi (szyfrowanie/maskowanie, zgodność z RODO).

## Technologie (Tech Stack):

#### React, TypeScript, Tailwind CSS, Supabase (PostgreSQL, Auth, Edge Functions), TanStack Query, Sentry.
